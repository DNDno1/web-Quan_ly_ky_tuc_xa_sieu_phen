# web-Quan_ly_ky_tuc_xa_sieu_phen
Sử dụng Xampp gồm Mysql và php để tạo một web quản lý ký túc xá, sử dụng kèm bootstrap và JQuery (Để cho có)

Các bước cài đặt để sử dụng:
  1. Tải Xampp gồm module apache và mysql để sử dụng
  2. Vào .../xampp/htdocs, tạo một file "website"
  3. lấy tất cả các file trên git để bỏ vào file (bao gồm bootstrap 5.3.8 và Jquery 4.0).
